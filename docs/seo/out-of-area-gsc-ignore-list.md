# Out-of-area Search Console noise

Planning note for the Oct 2026 keyword audit. These query patterns are lookalikes from other regions. Do not build pages, rewrite titles, or chase decay for them.

Ignore when the query names one of these places and the clinic has no appointment there:

- Williamsville (including `dermal fillers williamsville` and `medspa williamsville`)
- Ashburn
- Loudoun
- Ballston (including `prp facial in ballston`)
- Warrenton
- Culpeper

Williamsburg, James City County, Yorktown, Newport News, Toano, Norge, Lightfoot, New Town, Kingsmill, and Ford's Colony are in the real service area. A query that only shares a similar spelling with Williamsburg is not a local page to create.

This list is linked from the SEO roadmap issue #122.
